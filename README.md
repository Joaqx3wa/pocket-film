# POCKET//FILM

Editor de fotos en el navegador con estilos de cámara, frames y looks de color.

## Uso local

Abre `index.html` en un navegador. La foto de muestra incluida es `tokyo-sample.jpg`.

## Publicación

El flujo de GitHub Actions publica el contenido en GitHub Pages cada vez que se actualiza la rama `main`. Después del primer envío, revisa **Settings → Pages** y selecciona **GitHub Actions** como fuente si GitHub todavía no la activó.

El editor procesa las imágenes en el navegador.
